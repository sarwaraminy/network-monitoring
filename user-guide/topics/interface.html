User Guide

Finding your way around

Conventions that hold on every screen, so the rest of this guide does not repeat them.

The navigation panel

Screens are grouped down the left in four sections:

  • Overview — the Dashboard.
  • Security — Security Alerts, Suppressions, Threat Intel.
  • Capture — Capture by Interface, Capture by IP.
  • Administration — Delivery, Audit Trail, Ad Hoc Query.

Type into Search navigation… to filter the list. The ‹ control at the top collapses the panel to a narrow rail of icons, and the application remembers that choice for next time.

You will not see every entry. Screens restricted to administrators are hidden rather than shown and refused — see Who can do what.

Tables

Findings, rules, packets and query results are all shown in the same table, which behaves the same way everywhere:

  • Sort by clicking the arrows in a column heading.
  • Filter a single column from the funnel icon in its heading.
  • Search every column at once from the search box above the table.
  • Choose columns and switch to a denser row height from the controls at the top right of the table.
  • Page from the foot of the table, and set how many rows a page holds.

Severity

Every finding carries one of five severities, and they mean the same thing on every screen and in every message:

SeverityRead it as
CriticalSomeone is being attacked, or a credential has already been exposed. Look now.
HighReconnaissance or a known-bad destination. Look today.
MediumWorth explaining, often ordinary once explained.
LowInformational — a new device, for instance.
InfoHousekeeping. Never delivered to a person by default.

Severity is what the delivery threshold is measured against, so raising the threshold is what quietens an inbox without hiding anything from the alerts list.

Times

Times are shown in your browser's own timezone. A finding carries both a first seen and a last seen time, because repeats of the same finding are aggregated into one row with an occurrence count rather than one row each — see Security alerts.
